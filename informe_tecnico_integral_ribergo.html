01 DE QUÉ TRATA LA APLICACIÓN Y CÓMO SURGE LA IDEA

RiberGO es la primera plataforma digital progresiva (PWA) de transporte y logística bajo demanda diseñada exclusivamente para la realidad urbana y geográfica de Riberalta (capital de la provincia Vaca Díez, departamento del Beni, en la Amazonía boliviana).

El Contexto y Surgimiento de la Idea

Riberalta ostenta una de las tasas per cápita más altas de motocicletas en toda Sudamérica: más del 85% de la población se transporta a diario en mototaxis como su único medio de vida o movilidad. Sin embargo, este ecosistema operaba de manera 100% informal, a viva voz en las esquinas, bajo lluvias torrenciales y sin ningún respaldo tecnológico.

Las grandes aplicaciones internacionales como Uber, Didi o Yango no operan ni operarán en Riberalta porque requieren mapas satelitales corporativos que no contemplan las calles de tierra, los pasajes vecinales ni las dinámicas de pago en efectivo o QR directo de la Amazonía boliviana.

💡 La Chispa del Proyecto

La idea de RiberGO nace al observar que los vecinos debían caminar cuadras bajo el sol o lluvia para encontrar una moto disponible, mientras cientos de mototaxistas daban vueltas consumiendo gasolina cara sin saber dónde había pasajeros. La meta fue crear una plataforma propia, ligera, que corriera en cualquier celular básico y devolviera el poder de negociación al pueblo.

02 PROBLEMÁTICAS QUE SOLUCIONA RIBERGO

⚡
1. Incertidumbre y Abuso en Tarifas

Antes, el precio dependía del humor del conductor o la hora. RiberGO fija una tarifa base justa de 10 Bs y abre una sala de negociación directa para acordar precios razonables hacia barrios alejados.

🛡️
2. Inseguridad para Pasajeros y Choferes

Los pasajeros subían a motos sin saber quién los llevaba. RiberGO identifica al conductor, su nombre, foto, modelo de motocicleta y calificación comunitaria de 5 estrellas.

💸
3. Comisiones Usureras Multinacionales

Apps extranjeras cobran entre 20% y 30% al chofer. RiberGO opera con un modelo solidario de solo 1 Bs por carrera (90% limpio para el chofer) y 5 viajes iniciales gratis.

🛠️
4. Desamparo Mecánico (Auxilio / Remolcada)

Cuando una moto se apaga o pincha llanta en Riberalta, no hay grúas. RiberGO incluye el servicio de Remolcada con el pie, enviando un mototaxista para empujar la moto hasta un taller.

05 ARQUITECTURA DEL MOTOR REALTIME HÍBRIDO (0 MS)

En Riberalta, los mototaxistas y pasajeros no pueden esperar 5 o 10 segundos a que un servidor en Estados Unidos responda. Para garantizar inmediatez absoluta (0 milisegundos), RiberGO implementa el bus híbrido RealtimeSyncBus:

⚡ Sincronización Doble Simultánea

1. Canal Local Instantáneo: Usa BroadcastChannel y storage events. Cuando el pasajero pulsa "Pedir Mototaxi", la pestaña del conductor en línea salta al milisegundo.
2. Canal Cloud Firestore: Se actualiza en segundo plano para persistencia remota sin trabar la interfaz.

Filtro Antifantasmas

Se descartan automáticamente viajes con más de 5 minutos de antigüedad o que ya hayan sido aceptados por otro conductor, garantizando que el mototaxista solo vea solicitudes 100% reales.

1. services/apiService.ts — Motor RealtimeSyncBus (0 ms)

services/apiService.ts • RealtimeSyncBus TypeScript 
class RealtimeSyncBus {
  private channel: BroadcastChannel | null = null;
  private pendingRidesListeners: Set<(rides: any[]) => void> = new Set();
  private rideListeners: Map void>> = new Map();

  constructor() {
    if (typeof window !== 'undefined' && 'BroadcastChannel' in window) {
      this.channel = new BroadcastChannel('ribergo_realtime_sync_channel');
      this.channel.onmessage = (event) => {
        if (event.data?.type === 'RIDE_UPDATED') {
          this.notifyPendingRides();
          if (event.data.payload?.id) {
            this.notifyRide(event.data.payload.id, event.data.payload);
          }
        }
      };
    }
  }

  // Guarda en caché local compartida y difunde al instante (0ms)
  public saveRide(ride: any) {
    const rides = this.getActiveRides();
    const idx = rides.findIndex(r => r.id === ride.id);
    const updated = { ...(idx >= 0 ? rides[idx] : {}), ...ride, updatedAtMs: Date.now() };
    if (idx >= 0) rides[idx] = updated; else rides.unshift(updated);
    
    localStorage.setItem('ribergo_active_rides_cache_v3', JSON.stringify(rides));
    this.channel?.postMessage({ type: 'RIDE_UPDATED', payload: updated, timestamp: Date.now() });
    this.notifyPendingRides();
    this.notifyRide(updated.id, updated);
  }

  // Filtra solo carreras activas recientes menores a 5 minutos
  public getPendingRides(): any[] {
    const now = Date.now();
    return this.getActiveRides().filter(r => 
      r.status === 'SEARCHING_DRIVER' && 
      !r.driverId && 
      (now - (r.createdAtMs || 0)) < 300000
    );
  }
}
export const realtimeSyncBus = new RealtimeSyncBus();

09 ADECUACIONES A LA REALIDAD LOCAL RIBERALTEÑA

Para evitar barreras de entrada que harían fracasar una aplicación genérica en el oriente boliviano, se aplicaron ajustes directos solicitados por los mototaxistas de Riberalta:

🏍️
Sin Exigencia de Placa

Casi ningún mototaxista urbano en Riberalta cuenta con placa visible. Se eliminó la obligación de colocar placa para permitir el trabajo libre y digno de todos los choferes.

💵
Sin Métodos Abstractos

Se eliminó la selección engorrosa de pagos en el menú del pasajero. El acuerdo se liquida en persona de forma rápida: o en efectivo de mano a mano, o mediante Simple QR.

👤
Roles Claros y Limpios

Al ingresar como conductor, no se muestran banners repetitivos como "¿Quieres ser conductor en Riberalta?". Cada usuario ve solo lo que necesita para trabajar.

10 ARQUITECTURA PWA Y CONCLUSIÓN

RiberGO funciona como una Progressive Web App (PWA):

  • Instalación Directa: Se instala desde el navegador a la pantalla de inicio con un toque, sin descargas pesadas de tiendas ni cuentas de Google Play.
  • Peso Pluma (< 1.2 MB): Consume 50 veces menos almacenamiento que apps tradicionales como Uber (que pesan más de 60 MB), ideal para teléfonos económicos.
  • Service Worker (public/sw.js): Cachea recursos clave para cargar al instante incluso cuando la señal 3G/4G fluctúa en barrios periféricos.
